# MyProyectoDevOps


Sistema web para la administración y seguimiento de tareas, desarrollado como proyecto integrador para la asignatura **Gestión de Procesos de Software**. El proyecto implementa prácticas modernas de desarrollo colaborativo y DevOps, incluyendo control de versiones, integración continua (CI), entrega y despliegue continuo (CD), monitoreo y evaluación del rendimiento.

---

## Objetivo del proyecto

Desarrollar una aplicación web que permita gestionar proyectos y tareas mientras se aplican prácticas profesionales de ingeniería de software y DevOps.

---

## Funcionalidades

- Inicio de sesión de usuarios.
- Administración de usuarios.
- Administración de proyectos.
- Gestión de tareas.
- Asignación de responsables.
- Cambio de estado de tareas.
- Dashboard de seguimiento.
- Registro de actividades.
- API REST.

## Instalación

Clonar el repositorio

```bash
git clone https://github.com/usuario/myproyectodevops.git
```

Entrar al proyecto

```bash
cd TaskFlowmyproyectodevops
```

Instalar dependencias (se realizará en módulos posteriores)

```bash
npm install
```

Ejecutar el proyecto

```bash
npm start
```
